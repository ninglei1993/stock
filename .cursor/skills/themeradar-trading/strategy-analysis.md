# 策略诊断与半导体案例说明

## 1. 收益率低、波动大 — 是「抓主线」思路错了还是实现有偏？

**结论：主线雷达的「识别强势板块」与「用预警做日频交易」是两层问题。当前回测差，主要来自「交易规则 + 演示数据」，而非 Top5 评分完全无效。**

### 1.1 交易层（对回测伤害最大）

| 问题 | 说明 |
|------|------|
| fish_body 买点过窄 | 仅在 `STAGE_UP`（萌芽→发酵）买入，板块若缓慢走强、跳过 sprout 标签则**永不买入** |
| 环境双门槛 | `env_score>=60` + `can_long`；演示模式下大盘分随机，大量交易日无法开仓 |
| 仓位缩放 | `position_size=0.1` 使净值对单笔不敏感，但交易次数少时曲线呈「阶梯状」高波动 |
| 卖点仅看阶段跳变 | 未实现移动止盈、发酵内加仓；高潮识别偏晚时已在 ferment 末尾才卖 |
| 龙头成交价简化 | T+1 开盘价 + 合成/demo 行情，与真实龙头接力差异大 |
| fixed_hold 基准失真 | 不卖 + 期末按成本平仓，拉低对比可信度 |

**相对更不准的策略（若只选一个改）：`top5_rotation`** — 在 **climax 仍允许买入**，与「不吃鱼尾」相反，容易放大回撤。

**相对最符合产品定义但仍偏保守：`fish_body`** — 逻辑正确但**信号太少**（约 14 笔/年级别），胜率 21% 时净值必然难看。

### 1.2 评分层（影响「选谁」，影响回测次于买卖点）

| 问题 | 说明 |
|------|------|
| 相对强度权重仅 5% | 持续跑赢指数的板块，总分可能不如「涨停多但一日游」 |
| 龙头分对「趋势中军」不敏感 | 连板权重高，半导体趋势行情常是趋势龙头非连板 |
| 假主线过滤误伤 | 涨停少、资金缓流入的趋势板块可能被标「资金脉冲」并减半 |
| 扫描只入库有行情的板块 | DEMO 仅 15 个概念；JQData 未配时**根本没有全市场半导体板块** |

### 1.3 数据层（解释「为何没有 2026 半导体」）

见第 3 节。

## 2. 改进方向（按优先级）

1. **数据**：配置 `JQDATA_USER/PASSWORD`，`DEMO_MODE=false`，回测区间包含 2026
2. **板块池**：`ingest_day` / 回测 `max_concepts` 覆盖全市场或行业+概念并集；增加「半导体」「算力」「CPO」等概念映射
3. **fish_body 变体**（产品决策后改代码）：
   - 买入：`STAGE_UP` **或**（`ferment` 且 `STRENGTH_SURGE` 且 rank≤5）
   - 卖出：保留 EXIT，或 ferment 内回撤 >X% 止盈
4. **环境门槛**：回测可降至 `env_score>=50`，或分档仓位而非硬禁买
5. **指标**：max_drawdown 应按净值曲线计算（当前实现用单笔收益累加近似，会失真）

## 3. 为何 2026 初半导体算力大涨，回测/仪表盘却选不出？

需同时满足以下事实（**通常命中多条**）：

### 3.1 演示模式未覆盖真实板块

`DemoAdapter.DEMO_CONCEPTS` 仅 **15** 个概念，名称包括「芯片概念」「人工智能」，**没有**单独的「半导体」「算力」「CPO」等聚宽概念。

- 回测与扫描用的是**合成随机行情**（按日期+板块 hash），**不会复现** 2026 年真实半导体牛市。
- 即便「芯片概念」存在，其涨跌与真实 GN 板块无关。

### 3.2 回测区间与 2026 无关

界面默认回测常为 `2024-04-01 ~ 2025-04-01`，**不包含 2026 年初**。请新建 `2026-01-01 ~ 2026-05-16` 回测对比（仍受 DEMO 数据限制）。

### 3.3 fish_body 不买「已在主线上的板块」

真实半导体行情往往：
- 已在 **ferment/climax** 多日；
- 很少在回测里恰好出现「昨日 sprout、今日 ferment」的 `STAGE_UP` 日。

因此**不会触发买入**，Top5 里能看到也不代表回测会交易。

### 3.4 Top5 ≠ 回测持仓

仪表盘 Top5 按**当日总分**排序；回测只响应**预警事件**。板块可能高分但无 `STAGE_UP` 预警。

### 3.5 接入 JQData 后仍可能漏选的原因

- 概念拆分：涨幅在「存储芯片」「AI 应用」等子概念，不在单一「半导体」
- `max_concepts=30` 截断概念列表，小概念未入库
- 阶段机把「趋势慢牛」标成 dormant（涨停家数少）

## 4. 当前板块数量（DEMO）

| 类型 | 数量 |
|------|------|
| 适配器概念全集 | 见 `DemoAdapter.list_concepts()`（扩展后约 20+） |
| 每日扫描评分入库 | 等于当日 `SectorDaily` 行数（= 入库概念数） |
| 仪表盘展示 | Top **5** |
| 板块列表页 | 全部已评分板块（`/api/sectors`） |

接入 JQData 后，`universe_total` 为 `list_concepts()` 全量（可达数百），实际扫描量受 `max_concepts` 与配额限制。
