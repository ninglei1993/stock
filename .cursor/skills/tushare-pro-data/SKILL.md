# Tushare Pro Data Skill

## 用途

当任务涉及以下场景时使用本 Skill：
- 校验 Tushare 数据接口是否覆盖某类数据（行情、资金流、板块、龙虎榜等）
- 设计或排查 Tushare 适配器字段映射
- 分析“扫盘为空/字段为 0/板块无成分股”类问题
- 选择接口替代方案（同花顺板块、东财板块、打板专题等）

## 核心要求（必须执行）

当用户说“研究某个策略，要抓数据”时，必须先输出一个**简要判断**：

1. 这是哪类策略：趋势/主线、事件驱动、资金流、打板、基本面、指数轮动。
2. 该策略最小数据包是什么（至少 3 类）：
   - 价格与成交（行情）
   - 结构与范围（板块/成分/指数）
   - 驱动或确认（资金、龙虎榜、涨停炸板、公告/财务）
3. 再列出要调用的**文档接口名称（中文目录名）**，并写“为什么选它”。

## 简单判断规则（策略 -> 数据）

- 若策略关键词包含“主线/热点/轮动/板块强弱”：
  - 必选：同花顺行业概念板块、同花顺行业概念成分、同花顺概念和行业指数行情
  - 增补：板块资金流向（THS）、涨停最强板块统计、涨跌停和炸板数据
- 若关键词包含“资金行为/主力净流入/抢筹”：
  - 必选：个股资金流向（THS 或 DC）、板块资金流向（THS 或 DC）、大盘资金流向（DC）
  - 增补：每日指标、通用行情接口
- 若关键词包含“龙虎榜/游资/席位”：
  - 必选：龙虎榜每日统计单、龙虎榜机构交易单
  - 增补：市场游资最全名录、游资交易每日明细
- 若关键词包含“涨停/连板/炸板/打板”：
  - 必选：同花顺涨跌停榜单、涨跌停和炸板数据、涨停股票连板天梯
  - 增补：涨停最强板块统计、开盘竞价成交（当日）
- 若关键词包含“业绩/估值/基本面”：
  - 必选：利润表、资产负债表、现金流量表、财务指标数据
  - 增补：业绩预告、业绩快报、财报披露日期表

## 输出模板（每次都按此结构）

1. **策略类型判断**：一句话
2. **最小数据包**：列 3~6 项
3. **接口名称清单（文档目录名）**：
   - 接口名 A：用途
   - 接口名 B：用途
4. **可用性与权限检查**：
   - 日期是否交易日
   - 代码后缀是否规范
   - 接口是否需要更高积分/专题权限
5. **降级方案**：
   - 优先 THS -> 次选 DC -> 再退化到基础行情

## 常见结论模板

- **接口存在但结果为空**：先排查日期、权限、代码后缀、板块成分来源。
- **字段长期为 0**：优先核对接口字段名与单位，再核对是否读取到了 fallback 数据源。
- **板块详情空白**：多数是板块成分拉取失败或成分当日行情缺失，不一定是前端渲染问题。
- **策略无法回测复现**：通常是“策略语义需要的接口”与“实际使用接口”不一致，先对齐数据包。
